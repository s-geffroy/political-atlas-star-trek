Méthode : une relation n’est proposée que si une page lue (URL donnée) relie explicitement les deux faits. Types : **cause** (le premier fait est présenté comme une cause du second), **suite** (le second prolonge directement l’intrigue du premier), **même arc** (même arc narratif ou conflit nommé par la source). Les paires qui partagent un épisode ne sont pas reprises : le site les associe déjà.
