(champ `period` et en-tete « Période diégétique » des fiches 293, 295, 297).

  sources officielles disent seulement « 32nd century » (Paramount+,
  « Everything you need to know » ; startrek.com : « Set in the 32nd

  elle-meme incertaine (page « 32nd century » : « there is still no certainty

  3196 (fiche de Lura Thok, nee en 3145, 50 ans ; generique « Graduating
  Class of 3196 » de « Rubincon »).

  alignees.
