# Proposition V0.18 -- periodes floues relues sur les dates dites a l'ecran

Brouillon non publie (`docs/` est exclu du site). Recherche du 2026-11-13 sur les
73 entrees dont la periode n'est pas une annee (SFA exclues, tranchees en V0.17).
Regle (V0.17) : une annee n'est retenue que si elle est dite ou montree a l'ecran ;
une conversion de stardate ou une chronologie de reference est seulement « deduite ».
Citations : transcriptions chakoteya.net (fans) recoupees avec Memory Alpha (MA).
