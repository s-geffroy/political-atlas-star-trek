Les {{ R.relations }} relations documentées entre {{ R.noeuds }} événements, organisées en {{ R.composantes.size }} arcs. Un arc réunit des événements reliés entre eux, quelles que soient leurs séries ; seul un ensemble de plus de {{ R.seuil_decoupe }} événements, illisible d’un bloc, est découpé par série, et les relations entre ses morceaux sont listées sur chaque arc avec un lien vers l’arc d’arrivée. Chaque arc a son graphe, qui se lit de gauche à droite : un fait est placé après ceux dont il est la conséquence ou la suite.

Ce que montre ce réseau. Seules les relations établies explicitement par une source sont dessinées (méthode). Les liens « épisode commun », en gris, reprennent les associations déjà affichées sur les fiches, uniquement entre événements du réseau, pour relier les arcs. L’absence de lien n’est pas une absence de relation : elle signifie qu’aucune source lue ne l’établit.
